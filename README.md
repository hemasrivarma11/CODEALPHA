# 📌 Tasks Included

## 🔹 Task 1 — Basic Network Sniffer

### Objective
Develop a Python-based network sniffer to capture and analyze network packets.

### Features
- Captures live network packets
- Displays source and destination IP addresses
- Detects protocols such as TCP, UDP, and ICMP
- Displays packet payload data
- Saves captured packets into a `.pcap` file

### Tools & Technologies
- Python
- Scapy
- Npcap
- Wireshark

### Features

- Social engineering awareness
- Fake email and website detection
- Interactive quiz section
- Prevention and security best practices

### Topics Covered

## 🔹 Task 3 — Secure Coding Review

### Objective
Analyze vulnerable Python code and implement secure coding practices.

### Features
- Vulnerable code analysis
- Secure code implementation
- Password hashing using SHA-256
- Secure authentication mechanism
- Security recommendations and remediation

### Vulnerabilities Identified
- Hardcoded credentials
- Plaintext password storage
- Weak authentication mechanism
- Lack of encryption

### Tools Used
- Python
- hashlib module
